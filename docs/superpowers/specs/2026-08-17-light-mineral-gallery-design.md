# 라이트 미네랄 갤러리 전체 리디자인 설계

## 목표

`codex/brighter-preview`를 부분적으로 밝은 버전이 아니라 처음부터 끝까지 하나의 밝은 아트 디렉션으로 다시 설계한다. 첫인상은 세련되고 차분해야 하며, 중고 바이크 판매자가 부담 없이 문의할 수 있는 편안함과 현장 거래 전문업체의 신뢰를 함께 전달한다.

기존 어두운 미리보기, `main`, 운영 도메인과 DNS는 변경하지 않는다. 카피, 실제 사진, 콘텐츠 순서, 전화·카카오·네이버 링크, CTA 식별자와 인터랙션 동작도 유지한다.

## 디자인 원칙

- 밝은 사이트를 만들기 위해 흰색을 늘리지 않는다. 채도가 낮은 미네랄 그레이와 그레이지를 사용한다.
- 헤더부터 푸터까지 명도 차이를 완만하게 연결한다. 검정에 가까운 큰 배경 블록은 사용하지 않는다.
- 세련됨은 강한 그림자나 과도한 장식이 아니라 실제 사진, 비대칭 여백, 얇은 선과 절제된 색으로 만든다.
- 카드마다 다른 색을 쓰지 않는다. 본문 배경 두 단계와 카드 표면 한 단계만 반복한다.
- 딥 페트롤은 배경색이 아니라 글자·아이콘·로고의 기준색으로 사용한다.
- 브라스는 번호·진행선·보조 제목에만, 코퍼는 핵심 문의 CTA에만 사용한다.
- 카카오 노랑은 공식 카카오 문의 버튼 안에서만 사용한다.

## 색상 체계

| 용도 | 색상 | 적용 위치 |
|---|---:|---|
| 미네랄 캔버스 | `#DADDD8` | 히어로 기본면·거래 과정·견적 준비 |
| 갤러리 보조면 | `#E3E4DF` | 실제 사례·FAQ |
| 카드 표면 | `#F0EFEA` | 거래 단계·사례 정보·견적 항목·위치 카드 |
| 선택 단계 | `#D7D2C5` | 활성 거래 단계 |
| 스틸 브리지 | `#C8CECA` | 신뢰 근거 바·최종 문의 영역 |
| 푸터 토프 | `#B8BFBB` | 푸터 |
| 딥 페트롤 잉크 | `#0C1A1C` | 제목·주요 정보·아이콘 |
| 보조 그래파이트 | `#4A595B` | 설명·FAQ 답변·보조 정보 |
| 브라스 | `#6A4F2C` | 번호·진행선·보조 제목 |
| 코퍼 CTA | `#FF6645` | 핵심 문의 버튼 |
| 구분선 | `rgba(12, 26, 28, 0.17)` | 섹션·카드 경계 |

일반 본문은 최소 4.5:1, 아이콘·포커스 표시는 최소 3:1 대비를 유지한다. 코퍼 CTA는 딥 페트롤 글자를 사용한다.

## 섹션별 설계

### 헤더

- 배경을 반투명 갤러리 보조면으로 바꾸고 `backdrop-filter`를 절제해 사용한다.
- 하단에 얇은 스틸 계열 구분선을 둔다.
- 로고, 내비게이션과 전화 버튼은 딥 페트롤 글자를 사용한다.
- 카카오 버튼은 밝은 표면 위의 얇은 테두리 버튼으로 두고 공식 마크만 노랑을 유지한다.
- 고정 헤더 높이, 내비게이션 노출 폭과 44px 터치 영역은 변경하지 않는다.

### 히어로

- 현재 사진과 구조는 유지하되 사진의 밝기를 높이고 채도를 낮춰 차가운 금속 질감이 보이게 한다.
- 검정 오버레이를 제거하고, 왼쪽은 미네랄 캔버스가 충분히 불투명하고 오른쪽으로 갈수록 사진이 드러나는 밝은 편집형 그라데이션을 사용한다.
- 제목·설명·보조 문구는 딥 페트롤과 그래파이트로 전환한다.
- 보조 전화 CTA는 밝은 투명 버튼과 진한 테두리로 바꾼다.
- 모바일에서는 사진 위에 검정 막을 씌우지 않고 밝은 미네랄 워시를 사용해 같은 인상을 유지한다.

### 신뢰 근거와 본문

- 신뢰 근거 바는 스틸 브리지로 두어 히어로와 본문을 연결한다.
- 거래 과정과 견적 준비는 미네랄 캔버스, 실제 사례와 FAQ는 갤러리 보조면을 사용한다.
- 카드 표면은 모두 `#F0EFEA`로 통일하고 선택된 거래 단계만 브라스가 섞인 `#D7D2C5`로 구분한다.
- 사례 사진은 `saturate(0.78) contrast(1.03) brightness(1.02)`를 시작값으로 사용한다. 중앙 광고 문구가 더 튀지 않는 범위에서 실제 화면을 보고 미세 조정한다.
- 섹션 구분은 큰 명도 점프 대신 1px 구분선과 여백으로 표현한다.

### 최종 문의와 위치

- 딥 페트롤 배경을 스틸 브리지로 바꿔 본문에서 자연스럽게 이어지게 한다.
- 문의 문구는 딥 페트롤, 설명은 그래파이트를 사용한다.
- 위치 정보는 카드 표면 위에 배치해 문의 영역 안에서 한 단계 분리한다.
- 코퍼 카카오 CTA와 밝은 테두리 전화 CTA의 우선순위는 유지한다.

### 푸터와 모바일 고정 문의 바

- 푸터는 검정 대신 스모키 토프 배경과 딥 페트롤 글자를 사용한다.
- 모바일 고정 문의 바는 카드 표면에 가까운 반투명 밝은 바, 얇은 테두리와 짧은 그림자로 구성한다.
- 전화 영역은 밝은 표면과 딥 페트롤 글자, 카카오 영역만 공식 노랑을 사용한다.
- 표시·숨김 조건, 포커스 이동, safe-area와 터치 영역은 변경하지 않는다.

## 기술 범위

- 작업 브랜치는 `codex/brighter-preview`로 한정한다.
- 주요 변경 대상은 `app/globals.css`와 색상·대비·반응형 회귀 테스트다.
- 컴포넌트 마크업, 콘텐츠 타입, 외부 라이브러리와 이미지 파일은 원칙적으로 변경하지 않는다.
- CSS만으로 명확한 히어로 편집 구성을 만들 수 없을 때에만 기존 `Hero`의 래퍼 클래스를 최소 조정한다. 새 클라이언트 상태나 JavaScript는 추가하지 않는다.
- 다크모드 토글, 자동 테마, WebGL, 영상과 새 분석 도구는 추가하지 않는다.

## 검증

- 390px와 1440px에서 헤더·히어로·신뢰 바·본문·최종 문의·푸터의 실제 계산 색상을 고정한다.
- 렌더링 표면에 기존 대형 다크 배경 `#0C1A1C`, `#071315`가 남지 않는지 검사한다. 딥 페트롤은 글자와 작은 장식에는 허용한다.
- 일반 텍스트 4.5:1, 아이콘·포커스 3:1, 모든 주요 액션 44px 이상을 확인한다.
- 320·390·768·960·1440px에서 가로 넘침, 헤더 충돌, 줄바꿈과 모바일 고정 문의 바 겹침을 확인한다.
- 거래 단계 전환, 키보드, reduced-motion, JavaScript 비활성, FAQ, 200% 확대와 해시 이동 회귀를 재검증한다.
- `npm run verify`, `npx tsc --noEmit`, `npm audit --omit=dev`를 수행한다.
- Lighthouse 모바일 목표는 Performance 95 이상, Accessibility·Best Practices·SEO 100이다.

## 배포와 롤백

- 기존 주소 `https://codex-brighter-preview.bike-manager.pages.dev/`만 갱신한다.
- HTTP 200과 `X-Robots-Tag: noindex`를 확인한 뒤 사용자에게 공유한다.
- 기존 어두운 주소, `main`, 운영 도메인과 DNS는 변경하지 않는다.
- 전체 밝은 버전이 맞지 않으면 현재 중간톤 커밋 `b9e4fec`로 되돌릴 수 있게 유지한다.
