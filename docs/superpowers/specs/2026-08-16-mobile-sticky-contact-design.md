# 모바일 상시 문의 바와 카카오 채널 자산 설계

## 목표

모바일 방문자가 본문을 읽는 동안 전화와 카카오톡 문의 경로를 놓치지 않게 한다. 첫 화면의 큰 CTA와 마지막 문의 CTA는 그대로 살리고, 그 사이에서는 하단 문의 바를 거의 계속 노출한다. 카카오톡 영역에는 일반 말풍선 아이콘이 아니라 카카오가 제공하는 카카오톡 마크를 사용한다.

## 검토한 방식

1. **처음부터 끝까지 완전 고정**
   - 문의 경로는 가장 잘 보이지만 첫 화면 CTA와 중복되고, 마지막 CTA 및 본문 컨트롤을 가릴 수 있다.
2. **핵심 구간에서 거의 상시 노출 — 채택**
   - 히어로 문의 버튼이 화면에서 벗어나면 나타나고, 마지막 문의 CTA가 보일 때 숨는다.
   - 본문 링크나 FAQ 조작부를 실제로 덮는 순간에만 잠깐 숨겨 터치와 키보드 접근을 보장한다.
3. **섹션 단위로 자주 숨김 — 기존 방식**
   - 콘텐츠 가림에는 보수적이지만 진행 방법·FAQ 전체에서 문의 경로가 사라져 전환 흐름이 끊긴다.

## 확정 동작

- 적용 범위는 `760px` 이하 모바일이다. 데스크톱과 태블릿의 기존 헤더 문의 동작은 바꾸지 않는다.
- 히어로의 전화·카카오톡 CTA가 보이는 동안 하단 바를 숨긴다.
- 히어로 CTA가 화면에서 벗어난 뒤 하단 바를 표시한다.
- 진행 방법, 사례, 견적 준비, 지원/FAQ 구간에서는 기본적으로 계속 표시한다.
- 본문 링크·버튼·`summary` 또는 펼친 안내문이 하단 바의 실제 사각형과 겹치는 순간에는 바를 숨긴다. 섹션 전체를 기준으로 숨기지 않는다.
- 마지막 CTA가 화면에 들어오면 중복을 피하기 위해 바를 숨긴다.
- 숨김 상태에서는 `aria-hidden`, `inert`, `pointer-events`를 함께 적용한다.
- 바 안에 키보드 포커스가 있는 상태에서 숨겨져야 하면 현재 보이는 목적지로 포커스를 안전하게 옮기고, 임시 `tabindex`는 복원한다.
- iOS safe-area를 포함한 기존 하단 여백과 58px 이상의 터치 영역을 유지한다.

## 버튼 디자인과 문구

- 왼쪽: 딥 페트롤 배경, 흰색 전화 아이콘, `전화 상담`.
- 오른쪽: 카카오 공식 노랑 `#FEE500`, 검정 아이콘과 검정 글자, `사진 보내기`.
- 현재 Lucide `MessageCircle`은 카카오톡 버튼에서 제거한다.
- 카카오 공식 리소스 페이지에서 내려받은 **카카오톡 마크 자산**을 로컬에 원본으로 저장한다. 외부 CDN에 핫링크하지 않는다.
- 공식 자산의 형태·비율·색을 바꾸거나 BM 로고와 결합하지 않는다.
- 버튼은 실제 바이크매니저 카카오톡 채널 1:1 채팅 주소만 연다. 카카오가 업체를 인증·제휴했다는 표현은 사용하지 않는다.

## 구현 경계

- `StickyInquiryBar`가 노출 상태와 실제 충돌 판정을 담당한다.
- 연락처 URL과 CTA ID는 계속 `content/site.ts`를 단일 정보원으로 사용한다.
- 공식 아이콘은 별도의 작은 프레젠테이션 컴포넌트 또는 로컬 이미지로 제공하며, 장식 이미지이므로 링크의 접근 가능한 이름은 텍스트 `사진 보내기`가 담당한다.
- 외부 SDK, 분석 도구, API, 데이터베이스는 추가하지 않는다. 기존 `pf.kakao.com/.../chat` 링크를 유지한다.

## 검증 계약

- TDD RED에서 기존 구현이 진행 방법·FAQ 전체에서 바를 숨기는 것을 먼저 재현한다.
- 390px에서 히어로 CTA가 보일 때 하단 바가 숨고, 벗어나면 표시되는지 확인한다.
- 진행 방법과 FAQ의 비충돌 위치에서는 표시되고, 실제 컨트롤 충돌 때만 숨는지 확인한다.
- 마지막 CTA에서는 숨는지 확인한다.
- 바가 숨을 때 포커스가 보이지 않는 링크에 남지 않는지 확인한다.
- 카카오톡 영역의 문구, `#FEE500` 배경, 공식 로컬 자산, 58px 이상 터치 영역을 정적·브라우저 테스트로 고정한다.
- 320·390·760px에서 가로 넘침, safe-area, 본문 CTA 가림을 검사한다.
- 모션 감소와 JavaScript 비활성 환경에서는 핵심 전화·카카오톡 링크가 히어로와 마지막 CTA에 계속 남아 있어야 한다.

## 범위 밖

- 카카오 로그인이나 카카오 JavaScript SDK 도입
- 카카오톡 채널 친구 추가 자동화
- 데스크톱용 고정 문의 바
- 운영 `main`, DNS, 도메인, 분석 도구 변경

## 운영 반영

브랜치 미리보기에서 동작과 공식 자산을 먼저 확인한다. 사용자와 업체 확인 전에는 `main`에 병합하지 않는다.
