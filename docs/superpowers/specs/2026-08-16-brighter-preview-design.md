# 밝은 대안 미리보기 설계

## 목표

현재 신뢰형 리뉴얼의 구조·문구·문의 동작은 그대로 유지하면서, 본문을 더 밝고 친근하게 조정한 두 번째 비교용 미리보기를 만든다. 기존 `codex/trust-first-renewal` 미리보기와 운영 `main`은 변경하지 않는다.

## 시각 방향

- 전체 인상은 `라이트 60 / 다크 40`을 목표로 한다.
- 헤더·히어로·최종 문의·푸터는 딥 페트롤을 유지해 브랜드의 무게감과 CTA 대비를 보존한다.
- 거래 원칙 바, 거래 과정, 실제 사례, 견적 준비, FAQ는 웜 아이보리 계열로 전환해 읽기 부담을 줄인다.
- 버밀리언 CTA, 황동 포인트, 카카오 노랑은 현재 값을 유지한다.
- 다크·라이트 모드 토글은 추가하지 않는다. 이 버전 자체가 비교 가능한 밝은 아트 디렉션이다.

## 섹션별 변경

### 히어로

- 레이아웃과 카피는 변경하지 않는다.
- 실제 바이크 사진의 채도와 밝기를 소폭 올린다.
- 왼쪽 텍스트 영역의 어두운 그라데이션은 유지하고, 오른쪽 사진 영역의 검정 오버레이만 완화한다.
- 흰색 제목·설명·CTA의 대비는 WCAG AA를 유지한다.

### 거래 원칙 바

- 딥 페트롤 배경을 밝은 웜 카드 배경으로 바꾼다.
- 글자는 딥 페트롤, 아이콘은 황동색으로 사용한다.
- 4개 신뢰 근거와 반응형 그리드는 그대로 둔다.

### 거래 과정

- 섹션 배경은 밝은 아이보리, 단계 카드는 더 밝은 카드 표면으로 바꾼다.
- 진행선·테두리·태그·설명·안전 안내를 모두 밝은 표면에 맞는 딥 페트롤 계열로 재조정한다.
- 현재의 두 단계 전환, 키보드 조작, reduced-motion 및 JavaScript 비활성 fallback은 변경하지 않는다.

### 실제 사례

- 섹션과 카드 본문을 밝게 바꾸고, 사진은 기존보다 약간 더 선명하게 보이도록 한다.
- 사례 순서, 실제 블로그 링크, 이미지 크롭과 파일은 변경하지 않는다.
- 사진 영역 자체는 어두운 프레임을 유지해 바이크 사진과 밝은 카드 본문이 구분되게 한다.

### 견적 준비·FAQ

- 기존 웜 아이보리 톤을 유지하되 FAQ에는 한 단계 밝은 배경을 사용해 섹션 구분을 만든다.
- 카피·목록·details 동작은 변경하지 않는다.

### 최종 문의·푸터

- 기존 다크 톤과 버튼 구성을 그대로 유지한다.
- 모바일 고정 문의 바의 전화·카카오 버튼 동작과 색도 변경하지 않는다.

## 기술 경계

- 별도 브랜치 `codex/brighter-preview`에서만 작업한다.
- 컴포넌트 구조와 콘텐츠 데이터는 유지하고, 필요한 섹션 클래스와 `app/globals.css`만 최소 변경한다.
- 외부 라이브러리·이미지·SDK·분석 도구를 추가하지 않는다.
- 현재 이미지 파일과 전화·카카오·네이버 URL을 그대로 사용한다.

## 검증

- 밝은 거래 과정과 사례 섹션의 실제 계산 색상을 브라우저 테스트로 고정한다.
- 히어로 제목·설명과 밝은 본문 텍스트가 WCAG AA 대비를 만족하는지 확인한다.
- 320·390·768·960·1440px에서 가로 넘침과 CTA 겹침이 없어야 한다.
- 기존 정적 테스트와 브라우저 테스트를 모두 통과해야 한다.
- 새 Cloudflare Pages 브랜치 미리보기는 HTTP 200과 `X-Robots-Tag: noindex`를 확인한다.

## 배포 범위

- 비교용 브랜치 미리보기만 생성한다.
- 기존 어두운 미리보기, `main`, 운영 도메인, DNS는 변경하지 않는다.
