# 라이트 미네랄 히어로·CTA 리프레시 설계

## 목표

`codex/brighter-preview`의 밝고 편안한 미네랄 표면은 유지하면서, 강한 주황 CTA와 야간 네온 카페레이서 사진이 만드는 시각적 충돌을 제거한다. 첫 화면은 ‘중고 바이크 광고’보다 ‘차분하고 신뢰할 수 있는 현장 거래 전문업체’로 보여야 한다.

기존 어두운 미리보기, `main`, 운영 도메인과 DNS는 변경하지 않는다. 카피, 레이아웃, 전화·카카오·네이버 URL, CTA 식별자와 인터랙션 동작도 유지한다.

## 시각 방향

### CTA

- 전역 주요 CTA의 코퍼 `#FF6645`를 딥 유칼립투스 `#2F5D55`로 교체한다.
- CTA 글자와 아이콘은 웜 아이보리 `#F5F1E8`를 사용한다.
- hover와 focus에서는 밝기를 미세하게 낮춘 `#244A45`를 사용하고, 이동은 현재의 2px 범위를 넘지 않는다.
- 브라스는 보조 제목·번호·진행선에만 남겨 시각적 우선순위를 분리한다.
- 카카오의 공식 노랑은 모바일 고정 문의 바의 카카오 영역과 공식 마크에만 유지한다.
- 전역 포커스 링, 보조 전화 버튼, 44px 최소 터치 영역은 변경하지 않는다.

### 히어로 사진

- 외부 스톡·블로그·제조사 사진을 가져오지 않고, 이 페이지를 위한 신규 이미지를 참조 사진 없이 생성한다.
- 주제는 ‘밝은 자연광이 드는 정돈된 콘크리트 작업장의 프리미엄 맥시 스쿠터’로 고정한다.
- 실제 타깃 고객과의 거리감을 줄이기 위해 카페레이서·레이싱 바이크·초고가 투어러는 제외한다.
- 데스크톱에서는 바이크를 오른쪽 45%에 배치하고, 왼쪽은 한글 카피를 위한 밝고 단순한 여백으로 둔다.
- 모바일은 바이크 전측 3/4 구도가 중앙–우측에 남는 세로형 아트 디렉션을 별도로 만든다.
- 장면의 색은 스톤 그레이·연한 피트롤·절제된 유칼립투스로 맞춘다. 야간 네온, 강한 청록색, 주황 조명은 제외한다.
- 로고, 상표, 제조사 특징적 마크, 번호판, 문구, 워터마크, 사람은 포함하지 않는다.
- 바이크 구조는 실사처럼 자연스럽게 만들고 손상된 바퀴·잘못 붙은 부품·중복된 미러·불가능한 핸들 구조를 허용하지 않는다.

## 자산 생성과 적용

- 원본 히어로는 충분한 해상도의 가로 이미지로 생성한다.
- 선정한 생성 자산을 직접 검수한 뒤 `hero-bg-v2.webp`와 `hero-mobile-v2.webp`를 별도 파일로 최적화한다. 기존 자산은 롤백을 위해 덮어쓰지 않는다.
- 히어로는 300KB 이하, 모바일은 180KB 이하를 목표로 한다.
- OG 이미지는 같은 생성 자산의 1200×630 파생본으로 교체하되, 기존 메타데이터·용량·완전 디코드 검증을 계속 통과해야 한다.
- 실제 매입 사례 사진은 사실 증거 역할이 있으므로 이번 범위에서는 교체하지 않는다.
- 사이트에는 공개 이미지 CDN을 핫링크하지 않고 로컬 자산만 배포한다.

## 접근성·성능·회귀 방지

- 딥 유칼립투스 CTA와 웜 아이보리 글자는 4.5:1 이상의 대비를 유지한다.
- 320·390·768·960·1440px에서 CTA 줄바꿈, 가로 넘침, 히어로 크롭과 텍스트 가독성을 확인한다.
- 카카오·전화 링크, CTA `data-cta`, 모바일 고정 문의 바의 표시·숨김 조건은 변경하지 않는다.
- 히어로 LCP, 정적 export, JavaScript-off, reduced-motion, 200% 확대와 키보드 포커스 검증을 유지한다.
- 외부 자산 URL, 상표, 이미지 내 텍스트·워터마크·번호판이 배포 자산에 들어가지 않는지 정적·시각 검수한다.
- Lighthouse 목표는 Performance 95 이상, Accessibility·Best Practices·SEO 100이다.
