# 스포티 맥시 스쿠터·채널 신뢰 배지 디자인

## 목적

밝은 미리보기의 둔한 히어로 바이크와 서로 어울리지 않는 헤더 문의 버튼을 정리한다. 동시에 기존 사이트에서 의도했던 플랫폼 신뢰 신호를 사실에 맞는 세 개의 채널 배지로 되살린다.

운영 `main`과 운영 도메인은 변경하지 않는다. 밝은 미리보기는 `codex/brighter-preview`, 어두운 미리보기는 `codex/trust-first-renewal`에서 각각 갱신한다.

## 밝은 미리보기

### 히어로 이미지

- 참조 이미지를 사용하지 않고 데스크톱·모바일 이미지를 각각 새로 생성한다.
- 낮은 카메라 시점의 전면 3/4 구도와 길고 날렵한 차체를 가진 프리미엄 맥시 스쿠터를 사용한다.
- 차체는 새틴 그래파이트, 공간은 밝고 정돈된 콘크리트 검수 작업장으로 구성한다.
- 카피 영역인 왼쪽에는 충분한 여백을 남기고 바이크는 오른쪽에 배치한다.
- 특정 제조사와 구분되는 일반형 디자인을 사용하며 로고, 상표, 번호판, 문구, 워터마크와 인물을 넣지 않는다.
- 어색한 바퀴·포크·미러·핸들·차체 결합과 과도하게 큰 윈드스크린, 둔한 투어링 실루엣을 시각 검수에서 탈락시킨다.
- 기존 `v2`는 롤백 자산으로 유지하고 새 자산은 `v3` 파일명으로 추가한다.

### 헤더 문의 버튼

- 헤더의 카카오 버튼과 가시 전화번호를 제거한다.
- 헤더에는 `전화 상담` 버튼 하나만 남긴다.
- 버튼은 44px 이상의 짙은 페트롤 라운드 사각형이며 전화 아이콘과 짧은 라벨만 표시한다.
- 전화 링크, `data-cta="header-phone"`, 실제 전화번호가 포함된 접근 가능한 이름은 유지한다.
- 히어로 카카오 CTA와 모바일 하단 카카오·전화 고정 문의 바는 그대로 유지한다.

## 세 개의 채널 신뢰 배지

### 문구와 근거

다음 문구만 사용한다.

1. `네이버 플레이스`
2. `카카오 공식채널`
3. `당근 거래 활동`

`인증 업체`, `공식 인증`, `플랫폼 추천`이라는 표현은 사용하지 않는다.

- 네이버 배지는 현재 네이버 플레이스로 연결한다.
- 카카오 배지는 공개 채널 홈 `https://pf.kakao.com/_MzgSn`으로 연결한다.
- 당근은 사용자가 확인한 과거 거래 활동을 표시하되, 현재 업체와 일치하는 공개 프로필 URL을 확인하지 못했으므로 링크 없는 배지로 둔다.
- 향후 실제 당근 공개 프로필이나 게시물 URL을 받으면 링크만 추가할 수 있게 구성한다.

### 배치와 모양

- 별도 장문 섹션을 만들지 않고 기존 `TrustBar` 아래에 `바이크매니저 채널` 행으로 통합한다.
- 데스크톱에서는 세 개의 작은 라운드 카드가 한 줄에 놓인다.
- 모바일에서도 세 개가 한 줄에 보이도록 짧은 라벨과 작은 아이콘을 사용한다. 가로 스크롤과 자동 마키는 사용하지 않는다.
- 밝은 버전은 스톤 카드와 페트롤 글자, 어두운 버전은 딥 페트롤 카드와 밝은 글자를 사용한다.
- 네이버 초록, 카카오 노랑, 당근 오렌지는 아이콘에만 제한한다.
- 네이버·카카오 링크는 44px 이상의 클릭 영역과 키보드 포커스를 제공한다. 당근 배지는 비대화형 요소로 표시한다.

## 브랜치별 범위

### `codex/brighter-preview`

- 새 `v3` 히어로 데스크톱·모바일·OG 이미지
- 헤더 전화 상담 단일 버튼
- 세 개의 채널 신뢰 배지
- 밝은 팔레트에 맞는 배지 스타일

### `codex/trust-first-renewal`

- 기존 히어로, 헤더, 팔레트와 CTA를 변경하지 않는다.
- 세 개의 채널 신뢰 배지와 어두운 팔레트용 스타일만 추가한다.

### 제외

- `main` 병합
- 운영 도메인·DNS 변경
- 당근과 일치하지 않는 십정동 업체 프로필 연결
- 후기 수·평점·거래 건수 추가
- 플랫폼이 부여하지 않은 인증 표현

## 데이터와 컴포넌트

- `content/site.ts`에 채널 배지 데이터를 단일 정보원으로 추가한다.
- 배지 데이터는 `id`, `label`, `icon`, 선택적 `href`, `alt`를 가진다.
- 기존 `TrustBar`가 이 데이터를 렌더링하며, 링크 유무에 따라 `<a>` 또는 비대화형 요소를 사용한다.
- 공개 API, 서버, 외부 데이터베이스와 분석 도구는 추가하지 않는다.

## 검증

- 정적 export에서 정확한 세 문구와 네이버·카카오 URL, 링크 없는 당근 배지를 확인한다.
- `인증 업체`, `공식 인증`, 일치하지 않는 당근 프로필 URL이 export에 없는지 검사한다.
- 밝은 버전은 `v3` 히어로의 경로, 완전 디코딩, 규격과 용량 예산을 검증한다.
- 밝은 헤더에는 카카오 버튼과 가시 전화번호가 없고 `전화 상담` 링크와 `header-phone` 추적 ID가 남는지 검사한다.
- 두 버전 모두 320·390·768·960·1440px에서 배지 한 줄, 가로 넘침, 44px 링크 영역, 포커스 표시를 확인한다.
- 기존 모바일 고정 문의 바, 카카오·전화 CTA, reduced-motion, JavaScript 비활성, 200% 확대 회귀를 다시 실행한다.
- 각 브랜치에서 `npm run verify`, `npx tsc --noEmit`, `npm audit --omit=dev`와 모바일 Lighthouse를 수행한다.
- 각 브랜치만 푸시하고 Cloudflare 미리보기의 HTTP 200과 `X-Robots-Tag: noindex`를 확인한다.

- 어두운 버전은 현재 원격 커밋 `0c794288`으로 되돌릴 수 있다.
