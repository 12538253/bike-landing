# 바이크매니저 장점 우선 마케팅 카피 디자인

## 목표

현재 랜딩페이지의 사실성과 필수 안내는 유지하면서, 고객이 처음 읽는 문장은 제한이나 예외가 아니라 방문 매입의 편의와 신뢰를 말하도록 바꾼다. 전체 톤은 과장 광고가 아닌 자신감 있는 전환형 카피로 맞춘다.

## 선택한 방향

세 가지 후보 중 `전환형`을 적용한다.

- 안전형: 기존 문장의 순서만 긍정형으로 바꾼다.
- 전환형: 장점을 먼저 단언하고 조건은 짧게 뒤로 보내거나 접힌 안내에 둔다.
- 공격형: 최고가·즉시 방문·전 차종처럼 검증하기 어려운 보장을 사용한다.

전환형은 `빠르게 안내`, `직접 찾아감`, `현장에서 한 번에 진행`, `당일·야간 일정 조율`처럼 업체가 실제로 제공하는 편의를 적극적으로 말한다. `최고가`, `무조건`, `100%`, `즉시 출동`, `모든 차량`은 사용하지 않는다.

## 카피 원칙

1. 장점이 먼저 나오고 조건은 뒤에 온다.
2. 사진 견적은 예상 금액이며 최종 금액은 현장에서 확정한다는 사실을 보존한다.
3. 판매대금 전액 입금 확인 후 상차한다는 거래 원칙을 보존한다.
4. `24시간`은 언제든 문의할 수 있다는 장점으로 표현하고, 당일·야간 방문은 `일정에 맞춰 최대한 빠르게 조율`한다고 쓴다.
5. 명의·서류 예외는 기본 화면에서 겁을 주지 않고 접힌 상세 안내에서 진행 방법 중심으로 설명한다.
6. 개인 거래의 가격상 장점을 메인 화면에서 먼저 강조하지 않는다.
7. 같은 주의사항을 히어로·거래 경로·FAQ에서 반복하지 않는다.
8. 한국어는 짧은 능동문을 우선하고, 기계적인 병렬과 방어적인 행정 문체를 피한다.

## 화면별 변경

- 검색 메타: `직접 방문`, `빠른 예상 견적·방문 안내`, `입금 확인 후 상차`를 앞세운다.
- 히어로: `바이크는 그대로 두세요. 직접 찾아가 매입합니다.`를 핵심 제목으로 쓴다. 예상 견적 안내는 불확실성 경고가 아니라 현장 확정 과정으로 설명한다.
- 거래 경로: `바이크는 그대로, 확인은 현장에서.`로 단순화하고 직접 방문의 편의를 먼저 보여준다. 개인 거래 우위 문장은 제거한다.
- 견적 준비: `8가지만`이라는 부담보다 `사진 몇 장과 기본 정보`라는 쉬운 시작을 강조한다.
- 실제 사례: 검증 가능한 공식 블로그 기록을 업체의 자신감 있는 증거로 소개한다.
- 매입 범위·서류: 차종 범위를 단언하고 예외는 `진행 가능 여부와 준비 서류를 안내`하는 문장으로 바꾼다.
- FAQ: 방어형 질문을 고객이 실제로 기대하는 혜택형 질문으로 바꾼다. 특히 24시간 FAQ는 당일·야간 일정 조율을 먼저 말한다.
- 최종 CTA·푸터: `지금 사진`, `빠른 예상 견적`, `24시간 문의 가능`, `당일·야간 일정 조율`로 행동을 촉진한다.

## 검증

- 정적 export에 새 카피가 정확히 포함되고 이전 방어형 문구가 사라져야 한다.
- FAQ는 계속 세 개이며 답변은 각 두 문장 이내로 유지한다.
- 390px에서 히어로·거래 경로·FAQ·최종 CTA가 자연스럽게 줄바꿈되고 가로 넘침이 없어야 한다.
- 기존 전화·카카오·네이버 링크, 실제 사례 URL, JSON-LD, noindex 미리보기 동작은 바뀌지 않아야 한다.
- `npm run verify`와 `npm audit --omit=dev`를 통과해야 한다.
